Accessibility

A website for everyone.

CIASO serves people with many different backgrounds, languages and abilities. We want this website to be easy for everyone to use.

What we’ve done

This website was designed with the Web Content Accessibility Guidelines (WCAG) 2.2, level AA, as our target. This includes:

  • Plain language and short paragraphs
  • Text and button colours with strong contrast
  • Full keyboard navigation, a “skip to main content” link and visible focus outlines
  • Clear headings and page structure for screen readers
  • Text descriptions for meaningful images
  • Forms with clear labels, required-field markers and helpful error messages
  • Layouts that work on phones, tablets and computers, and respect for reduced-motion settings

Tell us about a barrier
